# Synthetic example data

**English** | [简体中文](README.zh-CN.md)

The sequences and ENST/ENSG identifiers in this directory are synthetic and do not represent real human genes. They are generated by [make_fixture.py](../../make_fixture.py) with random seed 6096.

The data include a 500 nt transcript, a matching miniature genome and five-column exon table, two 240 nt rRNA/bacterial references, and paired reads without UMIs for one NC and three TR samples. Each sample contains 2 bacterial rRNA pairs and 3 host rRNA pairs. The specified mRNA end counts are in [truth.json](truth.json); the candidate is at genomic position 219.

After installing the environment described in the [main README](../../../README.md), run from the repository root:

```bash
python3 tests/smoke.py
```

The command builds indices, aligns reads, and scores sites in a temporary directory, then removes the generated files. No complete references are needed, so this example can help you become familiar with installation and use. Results from synthetic sequences do not support biological conclusions.

All four rRNA filtering choices are exercised with raw and prepared reads. If UMI-tools is installed, the script also adds known 8 nt tags and checks UMI extraction and counting with bacterial filtering disabled.
