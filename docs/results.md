# Example results and outputs

**English** | [简体中文](results.zh-CN.md)

After running the human workflow in the [main README](../README.md), use this page to interpret counts, scoring status, and output files.

## Human subset

The [example data](../tests/data/human/README.md) contain NJU6096 (NC) and NJU6097–6099 (TR), with 1,000 read pairs per sample and no UMIs. With the matching references and software versions specified in the example, the stage counts are:

| Sample | Bacterial rRNA pairs removed | Human rRNA pairs removed | mRNA reads passing selection |
|---|---:|---:|---:|
| NJU6096 | 6 | 14 | 18 |
| NJU6097 | 81 | 41 | 13 |
| NJU6098 | 73 | 13 | 5 |
| NJU6099 | 78 | 29 | 2 |

Each accepted mRNA read has one selected alignment. The read branch counts R1 ends; rRNA removal is counted in read pairs.

The NC normalization totals for NJU6098 and NJU6099 are zero, so joint scoring reports `normalization_unavailable` and zero candidates. Shared coverage in this subset is insufficient; this does not establish whether Nm sites are present in the full libraries.

## Reading the outputs

| File | Interpretation |
|---|---|
| `SUCCESS` | All analysis steps completed successfully |
| `FAILED`, `logs/`, `stages.tsv` | Inspect the failed step, error messages, and exit status |
| `qc.html` | Open offline in a browser; generated by the default `--storage compact` mode |
| `<sample>/reads/mrna.filter.tsv` | Nine-column genomic read-end counts without a header |
| `mrna.reads.scored.tsv` | By default, only candidates passing the joint thresholds |
| `mrna.reads.score_summary.json` | Normalization status, samples included in scoring, and candidate counts |

When a score table contains only a header, also read its summary. Unavailable normalization, an empty intersection of covered sites, and successful scoring with no candidates are distinct outcomes. See [Scoring](scoring.md).

## UMI outputs

Samples with `umi=r1_3p8` also produce `<sample>/umi/mrna.filter.tsv`, a UMI family table, and grouping statistics. `mrna.umi.scored.tsv` and its summary are generated only when the NC and every TR have UMIs.

Read counts use accepted R1 reads as the counting unit. UMI counts use molecules grouped by exact matching within each sample, with tags containing `N` retained individually. Results and interpretation for Arabidopsis Col_NC31 / Col_TR31 are in the [UMI workflow](arabidopsis_umi.md#sample-results).
